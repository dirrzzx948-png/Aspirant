More Tools

Everyday utilities that run in your browser.

JSON Tools

Format, minify, validate, or sort JSON keys.

WhatsApp Direct Chat

Open a chat using an international phone number.

For Indonesian numbers, 08xx is converted to 628xx. No message is sent automatically.

Base64 Encoder / Decoder

SHA-256

QR Generator

Generate a QR code using an external image service.

The content is sent to the QR service when the image is requested. Do not enter passwords or confidential data.

API Tester

Send requests to public APIs from the server.

Only test APIs you are authorized to use. Server-side URL validation is important for protecting the backend.

Image Tools

Edit an image locally in your browser and export the result.

Basic local editing only. AI background removal, upscaling, object removal, and generative fill are not included.
