A lightweight workspace for common web utilities. Backend-dependent features need the Node.js server to be running.

TOOLS / TOOLKIT

More Tools

Everyday utilities that run in your browser.

JSON Tools

Format, minify, validate, or sort JSON keys.

WhatsApp Direct Chat

Open a chat using an international phone number.

For Indonesian numbers, 08xx is converted to 628xx. No message is sent automatically.

Base64 Encoder / Decoder

SHA-256

Create a SHA-256 hash in your browser.

QR Generator

Generate a QR code using an external image service.

The content is sent to the QR service when the image is requested. Do not enter passwords or confidential data.

API Tester

Send requests to public APIs from the server.

Only test APIs you are authorized to use. The server rejects many private addresses, but this basic filter is not a complete security boundary.

Image Tools

Edit an image locally in your browser and export the result.

Basic local editing only. AI background removal, upscaling, object removal, and generative fill require a real AI provider and are not included in this version.
